# 津达立线束打样报价编码 / Jinda wire-harness sample-quote numbering

Empty InvenTree plugin. No coding rules are implemented here, and none should be inferred from the class name.

The class `JindaHarnessQuoteCodingPlugin` subclasses `InvenTreePlugin` and adds no mixins. InvenTree discovers it from `INVENTREE_PLUGIN_DIR` (`/home/inventree/data/plugins` in the official image) and leaves it disabled until a staff user enables it in the Admin Center.

https://docs.inventree.org/en/stable/plugins/develop/
